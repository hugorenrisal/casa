# Código de conducta

Este proyecto adopta el [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

En resumen: se espera un trato respetuoso y constructivo en issues, pull requests y
discusiones. No se toleran el acoso, los insultos ni la publicación de datos personales de
terceros.

## Cómo informar

Si ves un comportamiento inaceptable, escribe un aviso privado desde
**Security → Report a vulnerability** o abre un issue sin datos personales pidiendo contacto.
Toda comunicación se trata con confidencialidad.
